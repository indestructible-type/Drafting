Candidate glyphs to add — Drafting Mono
========================================
Compiled 2026-09-14. ADDED 2026-09-14 to all six UFOs as TruFont template
slots: the names are appended to the end of public.glyphOrder (in the order
listed below) but have no .glif files yet, so TruFont shows them as ghost cells
and they are left out of built fonts until drawn.

Naming: on 2026-09-14 every "uniXXXX" glyph was renamed to its Glyphs "nice
name" (e.g. uni0259 -> schwa). The new glyphs use nice names too; the "uniXXXX"
names below are now their production names only, applied at build time via
the public.postscriptNames map in each UFO's lib.plist.

Round 2 — added 2026-09-15 (all six UFOs, same template-slot mechanism)
--------------------------------------------------------------------
Gaps found on re-checking terminal-app coverage:
- Braille had zero coverage, yet it is the most common terminal spinner
  encoding (dots, bounce, and binary frame sets all live here, and sets
  vary, so the whole block is covered): U+2800..U+28FF (256 slots,
  Glyphs names blank-braille, dots1-braille ... dots12345678-braille,
  codepoint order).
- U+2190 LEFTWARDS ARROW                            -> leftArrow
- U+21B3 DOWNWARDS ARROW WITH TIP RIGHTWARDS       -> downTipRightArrow
  (follow-through/prompt glyph)
- U+2510 BOX DRAWINGS LIGHT DOWN AND LEFT          -> boxLightDownAndLeft
  (completes the four light corners; heavier joins left out for now)
- U+2796 HEAVY MINUS SIGN (separators)              -> heavyMinus
- U+2731 HEAVY ASTERISK                             -> heavyAsterisk
- U+27A1 BLACK RIGHTWARDS ARROWHEAD                 -> rightTriangleBlackArrow
- U+2580 UPPER HALF BLOCK, U+2594 UPPER ONE EIGHTH BLOCK,
  U+2595 RIGHT ONE EIGHTH BLOCK                     -> upperHalfBlock,
  upperOneEighthBlock, rightOneEighthBlock (close the partial-block set)

Production names go through public.postscriptNames as before
(uni2190, uni21B3, uni2510, uni2796, uni2731, uni27A1, uni2580, uni2594,
uni2595, uni2800..uni28FF).

TruFont helper-ghost coverage for the new slots (bundled Inter/Noto):
braille YES (NotoSansSymbols2), leftArrow/downTipRightArrow YES (Inter),
checkmark-class dingbats incl. heavyAsterisk YES (Symbols2),
rightTriangleBlackArrow YES (Symbols2). upperHalfBlock/upperOneEighthBlock/
rightOneEighthBlock, like the Round-1 blocks, box drawing and heavyMinus,
have NO outline source in TruFont's bundled fonts, so those cells stay
empty until drawn -- they are still listed, selectable, and excluded from
builds. See sources/misc/trufont_glyphlist.txt: point TruFont's glyph-list
preference at it so unicode/helper resolution does not depend on glyphsLib
being installed (it is not in TruFont's requirements.txt).
